# BatailleNavale
BERTAULT Nolhan
07/12/2026
 
Pour le moment le code ne permet que d'ajouter le nom du joureur et de placer les navires sur le plateau
 
Pour les symboles j'ai choisi:
- '0' : pour notifier la présence d'un navire
- 'X' : si un bateau est touché
- '-' : si un tir est manqué
- ' ' : si la case est vide

Les erreurs sont prises en compte et sont notifiés au joueur, même si l'interface n'est pas encore optimal
