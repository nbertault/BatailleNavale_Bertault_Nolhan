# BatailleNavale
Pour les symboles j'ai choisi:
- '0' : pour notifier la présence d'un navire
- 'X' : si un bateau est touché
- '-' : si un tir est manqué
- ' ' : si la case est vide


Pour les codes d'erreurs de l'entrée des case:
- 1 : erreur dans la ligne
- 2 : erreur dans la colonne
- 3 : mauvais format
