BERTAULT Nolhan

Code permettant d'effectuer des parties de battaile navale. En premier lieu une page d'accueil s'affiche:
<img width="514" height="352" alt="image" src="https://github.com/user-attachments/assets/a48d1bd5-3949-4122-8c26-6606839eb19d" />

On se retrouve ensuite sur une page proposant d'entrer le nom des 2 joueurs:
<img width="334" height="197" alt="image" src="https://github.com/user-attachments/assets/18084c15-dc5f-489e-8c6e-a1a44f430ba5" />

Ensuite ce propose la phase de placement des navires, il suffit d'entrer la position de la première case et l'orientation avec les lettres 'V'ertical et 'H'orizontal:
<img width="395" height="499" alt="image" src="https://github.com/user-attachments/assets/d870f0e8-dedf-4a2a-9a51-63f700c16f6b" />
Les navires sont représentez par des O sur les cases correspondantes.
Le nom et la taille du navire que vous placez est affiché en dessous du plateau
Cette phase de placement ce passe en 2 étapes, le premier joueur place en premier tous ces navires puis le second joueur.

La phase de jeu commence ensuite. A gauche est représenté la grille radar du joueur et à droite sa flotte. En dessous il est affiché le nombre de navires restant pour les 2 joueurs.
Il est ensuite possible de choisir le type de tir (simple et en croix), puis les coordonnées sont demandées.
<img width="840" height="629" alt="image" src="https://github.com/user-attachments/assets/dc4d26c9-e303-45f3-be9a-1d1090e779c1" />

Le résultat du tir est ensuite affiché 
<img width="334" height="270" alt="image" src="https://github.com/user-attachments/assets/641daaf7-adc6-4f95-9288-29414a6ff2fe" />

Ensuite vien le tour du joueur 2
<img width="838" height="532" alt="image" src="https://github.com/user-attachments/assets/e9a5b14b-2b9a-4562-a2ce-e56a21d2b749" />

Voici la correspondance des symboles sur l'affichage:
- 'O' : pour notifier la présence d'un navire
- 'X' : si un bateau est touché
- '-' : si un tir est manqué
- ' ' : si la case est vide

Lorsque la partie est finie (un joueur n'as plus de navire en place) cet affiche est présenté:
<img width="527" height="307" alt="image" src="https://github.com/user-attachments/assets/3a86b1ab-f1b0-4e76-8cee-70c29221a138" />

Il est ensuite proposé de rejouer
<img width="383" height="55" alt="image" src="https://github.com/user-attachments/assets/3670c4c5-52e6-4d67-b12e-6f3ec9603f38" />

Si vous entrez 'O' vous retourner sur la page demandant le nom des joueur.
